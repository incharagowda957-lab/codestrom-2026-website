Website Building Challenge

Challenge 01 – CODESTORM 2026

Build. Create. Innovate.

Develop a website based on a meaningful idea or real-world purpose. Demonstrate creativity, technical skills and user-friendly design.


Mandatory Requirements

  • Include all three official logos.
  • Include all required website sections.
  • Implement at least three meaningful features.
  • Make the website responsive.
  • Maintain a public GitHub repository.
  • Deploy the website and provide a live URL.
  • Ensure the project is functional and accessible.

Rules & Regulations

Important guidelines for participants.

1. Participation Rules

Participants must complete registration, provide accurate information and follow the official instructions.

2. Project Development Rules

Develop a meaningful website, include all three official logos, required sections and at least three meaningful features.

3. Originality and Integrity

Submit original work. Open-source libraries and templates are permitted with appropriate customization and credit.

4. AI Tool Usage

AI tools may be used for learning, brainstorming, debugging and development. Participants must understand and test their code.

5. Design and Content Rules

Websites should have professional content, responsible use of images and a safe, user-friendly experience.

6. Submission Rules

Submit a public GitHub repository URL and a live deployed website URL through the official submission method.

7. Evaluation Criteria

Evaluation considers design, functionality, creativity, responsiveness, technical implementation and presentation.

8. Code of Conduct

Maintain respectful communication and follow the event instructions.
